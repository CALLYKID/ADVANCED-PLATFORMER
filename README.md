# ADVANCED-PLATFORMER (Part 1)

An advanced platformer game created on Scratch. Navigate through unique environments, explore hidden sections, and reach the final objective.

> **Note:** This project is currently a work in progress (Part 1). Some features may not work perfectly yet as updates are actively being made.

---

## 🎮 How to Play

* **Movement:** Use the **Arrow Keys** to run and navigate.
* **Vertical Exploration:** You can jump vertically to discover hidden or higher vertical platforms.
* **Objective:** Your core aim is to safely get to the end of the platform.

---
